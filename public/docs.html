Meta Social & SEO Analytics API

Facebook · Instagram · YouTube · LinkedIn · Pinterest · Google Search Console — one contract, one dashboard.

v4.1.0
New in 4.1: every metric in data.overview is self-describing (kind, unit, group, trend, hasData), zero-value metrics are no longer dropped, trends compare the second half of the range to the first, /api/combined passes full platform payloads through and adds data.summary, /api/health explains exactly what to fix, Pinterest boards and account stats are included, and the dashboard is served from /app.

Query parameters

ParamValuesEffect
date_presettoday · yesterday · last_7d · last_14d · last_30d · last_90d · last_365dSelects the window (default last_30d)
since / untilYYYY-MM-DDExplicit window; overrides the preset
compacttrueDrops all-zero days from timeseries (Meta, YouTube, GSC). Zernio timelines stay dense.
dimensionsdate · query · page · country · deviceGSC only. Anything but date returns data.topItems[]
comparefalseGSC only. Skips the previous-period window (saves one API call)
rowLimit1–25000GSC only. 1000 for date, 250 for groupings
syncfalseLinkedIn/Pinterest. Don't trigger the external-post sync
Zernio upstream limits: max range 366 days, page size 1–100 (the API paginates for you). Pinterest post-level impressions/clicks lag 24–48h after publishing. LinkedIn personal-profile analytics are only available for posts published through Zernio.

Metric kinds — how values are aggregated

kindAggregationFormattingExamples
sumΣ over the rangecompact integerimpressions, likes, clicks, reach
gaugelast value in the rangecompact integerfollowers, pins, boards, monthlyViews
ratemean of daily values0–10 with 1–2 dp + %ctr, engagementRate, avgViewPercentage
avgmean of daily averagesvalue + unitaverageViewDuration, GSC position
durationΣ with unit conversionh / min / sestimatedMinutesWatched
countΣ of itemsintegerposts published

Always read kind before summing anything. hasData:false means a genuine zero — the value is still present and should still be rendered (muted).

Trends

  • trend = % change of the second half of the range vs the first half.
  • previous = the first-half value the trend was computed against.
  • GSC additionally returns a real previous window of equal length (meta.previousRange).
  • For position, a falling number is favourable — the dashboard inverts the colour.

Getting Search Console credentials

  1. Google Cloud Console → new project (or existing).
  2. Enable the Google Search Console API.
  3. Create an OAuth 2.0 Client ID (Web application); add https://developers.google.com/oauthplayground as a redirect URI.
  4. OAuth Playground → ⚙️ → use your own credentials.
  5. Scope: https://www.googleapis.com/auth/webmasters.readonly → Authorize → Exchange → copy the refresh token.
  6. Verify your property in Search Console, then set GSC_SITE_URL. /api/gsc lists every verified site in meta.verifiedSites.
