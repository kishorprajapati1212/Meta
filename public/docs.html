Getting GSC Credentials

1. Go to Google Cloud Console → Create a new project (or use existing)

2. Enable Google Search Console API

3. Create OAuth 2.0 Client ID (Web application), add https://developers.google.com/oauthplayground as redirect URI

4. Go to OAuth Playground → ⚙️ → Use your own credentials

5. Select scope: https://www.googleapis.com/auth/webmasters.readonly

6. Authorize → Exchange → Copy Refresh token

7. Add your website to Google Search Console and verify ownership

8. Set GSC_SITE_URL in .env to your verified site URL

Query Parameters

date_preset: today yesterday last_7d last_14d last_30d last_90d last_365d

Custom range: ?since=YYYY-MM-DD&until=YYYY-MM-DD

Compact: ?compact=true — removes zero-value days

GSC dimensions: ?dimensions=query,page&rowLimit=50 — group by query/page/country/device

Response Shape

{
  "success": true, "platform": "gsc",
  "meta": { "dateRange": {"from":"2026-06-18","to":"2026-07-15"}, "siteUrl": "https://example.com", "dimensions": ["date"] },
  "data": {
    "overview": { "clicks": {"total":420}, "impressions": {"total":12800}, "ctr": {"total":3.28}, "position": {"total":8.4} },
    "timeseries": [ {"date":"2026-07-01","clicks":14,"impressions":520,"ctr":2.69,"position":9.3} ],
    "metrics": [ {"id":"clicks","label":"Clicks","values":[...],"summary":{"total":420,"average":14,"latest":18,"trend":12.5}} ]
  }
}

With dimensions=query: returns topItems[] instead of timeseries/metrics — top keywords by clicks
